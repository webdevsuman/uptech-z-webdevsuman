## Backend

- 0. **RBAC Setup**
- 1. **Instructor ->**
  - Course creation - Models, Media folders setup
  - Course management - CRUD
  - Upload videos, quizzes, and course materials.
  - Define course structure and pricing.
  - Monitor course performance with analytics.
  - Answer student questions via Q&A sections.
  - Post announcements for enrolled students.
  - Profile management -> Create and update instructor profiles with bio, qualifications, and photo.
